# Global Changelog, README, Logo/Banner & Contributors Rule

1. Always update `CHANGELOG.md` (and `.github/CHANGELOG.md` if present, following Keep a Changelog & Semantic Versioning under `## [Unreleased]`) and `README.md` automatically whenever making code changes, bug fixes, security fixes, or adding features in a project.
2. Always ensure every GitHub project has:
   - `.github/assets/logo.png` (and `.github/assets/logo.svg`)
   - `.github/assets/social-banner.png` (`1280×640`) embedded at the top of `README.md` with a unified badge bar
   - `CONTRIBUTORS.md` linked from `README.md`
   - `.github/FUNDING.yml`
