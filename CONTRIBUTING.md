# Contributing

Thank you for your interest in contributing to **gOOvER**'s projects!

## How to Contribute

### 🐛 Reporting Bugs
- Check if the issue has already been reported.
- Use the **Bug Report** template and include clear steps to reproduce, environment details (versions, OS, logs), and expected vs. actual behavior.

### ✨ Suggesting Enhancements
- Use the **Feature Request** template to describe the feature, its use case, and why it would be useful.

### 🔧 Pull Requests
1. Fork the repository and create your branch from `main`.
2. Ensure your code follows the existing code style and conventions of the project.
3. Update `CHANGELOG.md` under `[Unreleased]` (following [Keep a Changelog](https://keepachangelog.com/en/1.0.0/)) to document your changes.
4. Test your changes thoroughly.
5. Open a Pull Request with a clear description of what was changed and why.
