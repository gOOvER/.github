# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any of **gOOvER**'s projects, please report it responsibly instead of opening a public issue.

- **Email:** [info@goover.dev](mailto:info@goover.dev)
- **GitHub Security Advisories:** If enabled on the repository, please use the ["Report a vulnerability"](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) button under the **Security** tab.

Please include as much detail as possible:
1. Affected repository and version
2. Steps to reproduce the vulnerability
3. Potential impact and any suggested remediation

You will receive an acknowledgment within 72 hours, and we will work to release a fix as quickly as possible.
